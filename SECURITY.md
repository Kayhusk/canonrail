# Security policy

## Supported source

Security fixes target the current `main` branch. CanonRail has no stable release, and older commits may not receive updates.

## Report a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/Kayhusk/canonrail/security/advisories/new) to send the report privately.

Do not open a public issue with exploit details, private data, credentials, or proof-of-concept code.

Include the affected commit, impact, reproduction steps, and any suggested mitigation in the private report.
